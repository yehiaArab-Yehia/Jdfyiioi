# محادثة خاصة لشخصين

هذه واجهة GitHub Pages لمحادثة خاصة بين شخصين.

## مهم جدًا

GitHub Pages يستضيف HTML/CSS/JavaScript فقط، ولا يوفر قاعدة بيانات أو WebSocket للمراسلة اللحظية.

لذلك هذه الحزمة تحتوي على **واجهة جاهزة**، لكن لا يمكن جعل الرسائل تصل من هاتف إلى هاتف بمجرد رفعها إلى GitHub Pages.

لتحويلها إلى نسخة لحظية حقيقية نحتاج خدمة realtime واحدة أو سيرفرًا خاصًا.

### الحسابات التجريبية

- يحيى: `123456`
- الصديق: `654321`

هذه الحسابات تجريبية داخل المتصفح وليست نظام أمان حقيقيًا.

## الخطوة التالية

عند اختيار طريقة الاتصال اللحظي، يتم تعديل `app.js` لإرسال واستقبال الرسائل، وتسجيل:
- ✓ تم الإرسال
- ✓✓ تم التسليم
- ✓✓ باللون الأزرق = تمت القراءة

ولا تحتاج الواجهة نفسها إلى تغيير كبير.
